# Archivio storico — non usare questi launcher

`2026-09-06/` conserva integralmente i file precedenti al riordino: download
storici, evaluation isolate/unificate, smoke test e relativi report.
Non dipendiamo da questi file durante l'esecuzione corrente.

I comandi e i percorsi interni dei documenti qui archiviati descrivono il
layout dell'epoca; non sono istruzioni operative aggiornate. Gli script sono
conservati come evidenza, non come alternative da lanciare dalla nuova posizione.
Pesi ufficiali, dataset e risultati delle evaluation complete sono preservati;
la pulizia degli artefatti smoke è documentata nel README operativo.

Per lavorare usare soltanto i quattro entry point descritti nel
[README operativo](../README.md): `envs.sh`, `assets.sh`, `evaluate.sh`, `train.sh`,
tutti con `sbatch`.
